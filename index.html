Quick Setup Guide

Connecting your Alexa Routines to this standalone remote

🔗 Option 1: URL Routine Trigger (Virtual Smart Home) Simplest for Routines

  1. Enable the free "URL Routine Trigger" skill in your Alexa App and link your Amazon account.
  2. Visit virtualsmarthome.xyz/url_routine_trigger/ to create a named trigger (it appears in Alexa as a Virtual Doorbell).
  3. In the Alexa App, create a Routine with When this happens → Smart Home → [Your Trigger Name].
  4. Copy the Activate URL (`https://www.virtualsmarthome.xyz/url_routine_trigger/activate.php?trigger=...`), click ＋ New Button here, select URL Trigger, and paste it in!

🐵 Option 2: Voice Monkey (API v3) Routines + Live TTS Speech

  1. Enable the Voice Monkey skill in Alexa and log into the Voice Monkey Console.
  2. Copy your API v3 Token and save it once in this app's Settings (⚙️) modal.
  3. Create a Routine Trigger device in Voice Monkey (e.g., study-lights) and paste only that Device ID into any button on this remote.
  4. For live Text-to-Speech announcements, add an Echo Speaker device in Voice Monkey and use the Announce (TTS) bar at the top of this remote!
💡 Built-in Local HTML & CORS Protection

This remote automatically dispatches webhooks with mode: 'no-cors' and cache-busting timestamps, so you can save this single .html file directly to your phone's home screen or desktop and trigger routines with zero browser CORS blocks.

3. Deploy to GitHub Pages in 60 Seconds

  1. Create a new repository on GitHub (e.g., alexa-remote) and upload index.html, manifest.json, and sw.js to the root folder.
  2. Go to your repo's Settings → Pages, set Branch to main (folder /root), and click Save.
  3. Open your live URL (https://<username>.github.io/alexa-remote/) in Chrome on Android (or Safari on iOS).
  4. Tap the "Install App" button in the top bar (or browser menu → Add to Home screen / Install app) to launch it full-screen like a native remote!
